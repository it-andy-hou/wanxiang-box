# 修复 SSH 工具箱 7 个已确认 Bug

## 修改清单

### 1. Bug 3：批量导入主机端口去重失效
**文件**：`src/main/main.js`（`host-batch-import` IPC，约 1095-1160 行）
- 在循环开头统一归一化端口：`const recordPort = parseInt(record.port, 10) || 22;`
- 去重 key 与 `existingHosts.find` 均改用 `recordPort`；已有主机侧用 `(parseInt(h.port, 10) || 22)` 比较，解决 `undefined`/`"22"` 与 `22` 不相等导致的重复导入
- 新增主机对象的 `port` 字段也改用 `recordPort`

### 2. Bug 4：调整调度间隔后工程定时任务停摆
**文件**：`src/main/taskScheduler.js`（`setCheckInterval`，约 274-277 行）
- `this.start(this.taskExecutor)` 改为 `this.start(this.taskExecutor, this.projectTaskExecutor)`

### 3. Bug 5：工程并行步骤 SSH 连接表互相覆盖
**文件**：`src/main/projectTaskExecutor.js`
- 新增私有辅助 `_getExecutionConnections(executionId)`：懒创建 execution 级总连接表（executionId → Map）
- `_executeBatchScript`：不再 `set/delete` 整个 executionId 映射，改用复合 key `${step.id}:${host.id}` 向总表注册/移除连接
- `_runExecution` 末尾（`stopFlags.delete` 旁）补充 `activeConnections.delete(executionId)` 兜底清理
- `stopExecution` 现有遍历断连逻辑不变（总表结构兼容）

### 4. Bug 6：上传步骤无法被中止
**文件**：`src/main/sshService.js` + `src/main/projectTaskExecutor.js`
- `sshService.uploadFile`：连接建立后调用 `options.onConnectionCreated?.(connection)` 暴露连接引用（调用方负责登记，dispose 幂等，重复 dispose 安全）
- `projectTaskExecutor._executeUploadStep`：
  - 传入 `shouldCancel: () => !!this.stopFlags.get(executionId)`（`uploadFiles` 已支持文件间取消检查）
  - 传入 `onConnectionCreated` 回调，把当前传输中的连接按 `${step.id}:${host.id}` 登记进 execution 总表，`finally` 中移除
  - 这样 `stopExecution` 的强制断连可立即中断传输中的 SFTP

### 5. Bug 7：脚本查看弹窗标签显示 [object Object]
**文件**：`src/renderer/js/taskExecution.js`（约 233 行）
- `escapeHtml(tag)` 改为 `escapeHtml(tag.value ?? tag)`，兼容对象标签与历史字符串标签

### 6. Bug 8：任务执行失败后 stopFlags/activeConnections 泄漏
**文件**：`src/main/taskExecutor.js`（`executeTask` catch 分支，约 169-184 行）
- catch 中补充 `this.stopFlags.delete(taskId); this.activeConnections.delete(taskId);`

### 7. Bug 12：CRLF 换行脚本远程执行失败
**文件**：`src/main/sshService.js`（`executeScript` 开头）
- 写远程文件前归一化：`scriptContent = String(scriptContent).replace(/\r\n/g, '\n').replace(/\r/g, '\n');`
- 一处修改覆盖 taskExecutor / projectTaskExecutor / 直接调用全部路径

## 验证方案

- 人工走查：批量导入重复数据去重、调度间隔修改后定时工程仍触发、并行步骤执行中点击停止能断开全部连接、上传中停止能中断、查看脚本标签正常显示、任务失败后 Map 无残留、粘贴 CRLF 脚本可正常执行
