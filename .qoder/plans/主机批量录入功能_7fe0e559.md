# 主机批量录入功能实施计划

## 1. 主进程 main.js — 扩展 `host-batch-import` IPC（约 L1079）
- 入参新增 `skipExisting`（默认 false，向后兼容 Excel 导入）。
- `skipExisting: true` 时遇到已有主机（IP+端口+用户名相同）不更新，记入 `results.skipped = [{ip, reason}]`。
- 循环内用 `seenKeys` Set 追踪已插入记录，防止批内重复（现有代码只查库内已有，批内重复会漏）。

## 2. 渲染进程 hostService.js — 新增 `batchAddHosts(fields, ips)` 方法
- 入参：公共字段（端口/用户名/密码/私钥/系统/应用/机房/环境/负责人/描述/标签/主机名前缀）+ IP 数组。
- 主机名规则：前缀为空 → `hostname = ip`；有前缀 → `${前缀}-${ip}`（保证唯一可追溯）。
- Electron 环境调用 `host-batch-import`（带 skipExisting: true）；非 Electron 环境（localStorage）循环调 `addHost` 兜底，"已存在"错误归入 skipped。
- 完成后刷新本地缓存，返回 `{added, updated, skipped, errors}`。

## 3. components.js — HostForm 增加「单台/批量」录入模式
- constructor 新增 `entryMode = 'single'`；仅在 add 模式显示切换 Tab（编辑模式不显示）。
- 表单结构调整（createForm）：
  - 顶部新增 `.entry-mode-tabs`（单台录入 / 批量录入），样式参照 kbd-chip/tab 风格（tokens.css 变量）。
  - 新增隐藏的批量区块 fieldset `#batchEntrySection`：IP 多行 textarea（等宽字体，min-height 160px，占位示例）、主机名前缀输入框（可选）、实时统计区 `#batchIpStats`。
  - 单台 IP/主机名 form-group 加 id（`#hostnameField`/`#ipField`），执行环境 fieldset 加 id，便于批量模式下隐藏。
- 切换逻辑 `switchEntryMode(mode)`：
  - 批量模式：隐藏 hostname/ip 单台字段、测试连接按钮、收集信息按钮、持续添加按钮、执行环境 fieldset（这些均依赖单台 IP）；显示批量区块；保存按钮文案改「批量添加」。
  - 单台模式：恢复原状。
- IP 解析 `parseBatchIps(text)`：分隔符正则与批量搜索弹窗一致 `/[,，;\uff1b\/\s|]+/`，返回 `{uniqueIPs, dupCount, invalidTokens}`，用 `Utils.validators.isIP` 校验。
- 实时统计 `updateBatchIpStats()`：显示 有效 N · 批内重复 M（自动去重）· 已存在 K（对照 `window.hostService.hosts` 按 ip+port+username 判定）· 无效项列举。
- 提交 `saveHostBatch()`：
  - 校验用户名/端口（复用 validateField），IP 无效项存在则阻断提交并提示。
  - 已存在 IP 不发送（客户端预过滤），服务端 skipExisting 作为兜底。
  - 调 `window.hostService.batchAddHosts(...)`，结果摘要显示在 `#batchResult` 区块：成功 N 台、跳过 M 台（已存在）、失败明细。
  - 有新增即触发 `onSave()` 刷新列表；全部成功且无错误 → 关闭模态框 + 成功通知；存在 errors → 保留模态框展示明细。
- `saveHost()` 顶部路由：entryMode === 'batch' 时转调 `saveHostBatch()`。

## 4. components.css — 新增少量样式
