# UI 深色控制台整体重构计划（对齐 DESIGN.md v2.0.0）

## 目标与边界
- **目标**：渲染层完全对齐 `.qoder/DESIGN.md` 的深色高密度控制台体系（分层表面、Electric Sky 主色、Inter + JetBrains Mono、语义状态色、紧凑尺寸）。
- **边界**：只改 `src/renderer/` 下的 HTML/CSS 及 JS 中的样式类选择器；不改业务逻辑、IPC、主进程。
- **字体策略**：直接使用规范的回退字体栈（`Inter, system-ui, ...` / `JetBrains Mono, SF Mono, Consolas, monospace`），不引入字体文件依赖。

---

## 阶段 1：Design Tokens 地基（新文件）

**新建 `src/renderer/css/tokens.css`**（在 index.html 中置于 main.css 之前加载）：
- `:root` 定义全部 token：4 层表面色（`--canvas-base:#09090b`、`--surface-subtle:#121215`、`--surface-card:#18181b`、`--surface-float:#202024`、`--surface-active:#27272a`、`--overlay`）、边框（subtle/default/strong/focus）、文本 5 级、primary 三态 + glow、5 组语义状态色（bg/fg/border）、chart 5 色。
- 尺寸 token：圆角（xs 3px / sm 5px / md 8px / lg 12px / pill）、间距、组件高度（header 48px / sidebar 240px / 折叠 64px / nav item 36px / 表头 36px / 行 42px / 控件 32px）。
- 字体 token：`--font-ui`、`--font-mono`、正文字号 13px/12px/11px。
- 全局数字规则：在数值/时间/IP 相关类上统一 `font-feature-settings: "tabular-nums" 1; font-variant-numeric: tabular-nums;`。
- 全局滚动条改深色（`#3f3f46` thumb / `#121215` track）。

**修改 `index.html`**：第 7 行前插入 `<link rel="stylesheet" href="css/tokens.css">`。

## 阶段 2：应用外壳重构（结构 + main.css + navigation.js）

1. `header.app-header`：降为 48px，`canvas-base` 底 + 底部 1px `border-subtle` + `backdrop-filter: blur(12px)`；左侧保留折叠按钮（改为控制侧边栏 240↔64px 折叠，不再是隐藏/显示）+ logo + 标题；右侧保留 `connectionStatus` 与设置按钮；删除 `header-center`/`main-nav`（8 个 `nav-item` 移入侧边栏）。
2. `aside.sidebar` 改造为规范 `sidebar-nav`：顶部为导航列表（8 个 `.nav-item`，36px 高，`data-page` 属性保持不变以兼容 `navigation.js` 的 `[data-page]` 查询）；底部保留原「快速操作」「统计信息」区块（stat 卡片换 token 样式）。
3. 清理与浅色主题冲突的内联样式（如 `searchStatusBar` 的 `#e8f4fd`、`resetAllBadge` 的 `#dc3545` 等改为引用 class）。

**`main.css` 重写外壳**：
- `body`：`#09090b` 底、`#d4d4d8` 文字、13px、`--font-ui`。
- `.app-header`：48px / 无渐变（删除紫渐变）/ `0 16px` padding。
- `.sidebar`：240px、`canvas-base` 底、右侧 1px 边框、新增 `.sidebar.collapsed`（64px，文字隐藏、仅图标）；nav item：hover `surface-subtle`、active `surface-card` + 左侧 2px primary 指示条。
- `.content`/`.page-header`/`.toolbar`/`.page-content`：全部换 `canvas-base` 底 + `border-subtle` 分隔；`page-header h2` 用 heading-page（20px/600）。

- 删除 nav-item 顶部导航相关响应式媒体查询，重写折叠逻辑样式。

**`navigation.js` 小改**：
- `sidebarToggle` 行为：由"宽度归零"改为 toggle `.collapsed` class（240px↔64px）。
- 高亮逻辑 `Utils.$$('.nav-item')` / `[data-page]` 不变（类名保留）。
- 顺带检查 `app.js`/`connectionMonitor.js` 中对 `.status-indicator` 文案与类的操作是否兼容新徽章样式（只调类名映射，不动逻辑）。

## 阶段 3：公共组件重写（components.css）

1. **按钮**：`.btn` 基类 32px 高 / radius 5px / 12px 字号 / 无 transform 无涟漪；`.btn-primary` = `#38bdf8` + `#09090b` 文字（hover `#0284c7`、active `#0369a1`）；`.btn-secondary` = `surface-subtle` + 1px 边框；`.btn-danger/.btn-warning/.btn-success` 映射到语义 critical/warning/healthy token（半透明底 + 亮色前景）；`.btn-sm/.btn-lg/.btn-icon` 同步调整。
2. **表单**：`.form-control` = `surface-subtle` 底、`border-subtle` 边框、focus `border-focus`（#38bdf8）、32px 高、radius 5px、12px 字号；`select` 同步；清除所有 `background-color: white !important` 与 autofill 白色覆盖（改为 token 色适配 autofill）。
3. **状态徽章**：合并 components.css 中 3 处重复定义；统一 pill 圆角、`2px 8px` padding、11px/500 字重、语义 token（healthy/warning/critical/info/neutral 的 `rgba 0.12` 底 + `0.25` 边框 + 亮前景）。同步改造 `.status-badge.status-*`、`.task-type-badge`、`.task-source-badge`、`.badge`、`.tag-chip`。
4. **表格**：容器 `surface-card` + 1px `border-subtle` + radius 8px；表头 36px 高、`surface-subtle` 底、12px/600；行高 42px（padding 收紧至约 `10px 12px`）、hover `surface-subtle`、分隔线 `border-subtle`；去掉 inset 阴影 hover 效果；排序箭头颜色改 primary。
5. **模态框**：`.modal-overlay` = `rgba(0,0,0,0.75)`；`.modal` = `surface-float` 底 + `border-default` + radius 12px + 规范阴影，去掉 scale 弹跳动画改淡入；header/footer 边框与底色换 token。
6. **分页**：`.pagination-btn` 32px、active 用 primary；底色 `surface-card`。
7. **统计卡片**：`.stat-card` 系列**删除三色渐变**，改 `surface-card` + 1px 边框 + 语义前景色数字（mono-metric + tabular-nums）。
8. **Toast/Tooltip/加载**：Toast 换 `surface-float` 深色；tooltip 换 Layer 2 浮层；loading 主色改 `#38bdf8`。
9. **进度条**：`progress-fill` 单色 primary（去掉蓝绿渐变），进度文字 mono + tabular-nums。

## 阶段 4：清理 enhancements.css 冲突

该文件以覆盖形式存在大量违规样式，处理策略：
- **删除**：渐变按钮变体（`#667eea→#764ba2` 等 6 组）、`.btn:before` 涟漪、hover translateY/大阴影、渐变表头、渐变状态徽章、渐变 toast header、`will-change: transform` 微交互块。
- **改写**：滚动条块（阶段 1 已进 tokens.css，此处删除）、focus 光圈统一为 `border-focus`、checkbox `accent-color` 改 `#38bdf8`。
- **保留并换肤**：脚本目录树（`.script-sidebar`、`.category-tree`）、tag-chip、快捷面板、文件上传 Bento 网格与 dropzone——底色/边框/高亮全部映射 token（dropzone 激活态用 `primary-glow`）。

## 阶段 5：页面级样式替换（components.css 后半 + 少量 JS 类）

- **执行监控区**（`te-` 前缀）：`.te-config-card/.te-stat-card` 换 `surface-card`；`.te-stat-value` 用 mono 28px/600 + tabular-nums + 语义前景色；`.te-label`、`.te-host-chips`、`.te-options-row` 边框换 token；进度与状态点颜色换 primary/语义色。
- **结果概览**（`result-` 前缀）：容器/卡片本身已是深色，但色值（`#1e1e1e/#2d2d2d/#3d3d3d`）统一替换为 token 表面色与边框色；`result-success/failed/running` 左边条换语义 token；duration 徽章 mono。
- **工程任务**（`pt-` 前缀）：同上，统一 token。
- **终端/日志**：`.te-terminal`、`#executionLog`、`.pt-output-pre` 等字体统一 `--font-mono`（去掉 `Courier New` 硬编码），字号 12px。
- **历史/调度/工程任务列表**、批量操作栏（`.batch-actions` 浅蓝底换 `primary-glow` + `border-focus`）、搜索状态条、`view-toggle`/`filter-btn` 按钮组：全部 token 化。
- **JS 内联样式排查**：`grep` `js/` 目录中 `style.background`、`style.color`、十六进制色值（如 taskExecution.js、components.js 动态生成 DOM 处），改为引用 class 或 token 变量色；重点是动态生成的状态徽章、结果卡片、日志条目。
- **HTML 内联浅色样式**：index.html 中 `#f8f9fa`、`#e7f3ff`、`#6c757d` 等内联色逐一替换（约 20 处）。

## 阶段 6：验证

1. `npm start` 启动应用，逐页目检：主机管理、工程任务、脚本管理、脚本执行、命令执行、文件上传、任务调度、任务记录。
2. 验收清单：
   - 无残留紫色渐变 / 白色大底 / `#3498db`、`#007bff`、`#667eea` 色值（`grep -rn "#3498db\|#007bff\|#667eea\|#f8f9fa" src/renderer/css/` 应为 0 结果）；
   - 侧边栏折叠 240↔64px 正常，导航高亮正确；
   - 表格排序、分页、批量选择等交互不受影响；
   - 模态框（添加主机/导入 Excel/SSH 密钥/批量操作）文字可读性检查；
   - IP/时间/计数列使用等宽字体且数字不抖动。
3. 修复目检发现的问题后完成。
