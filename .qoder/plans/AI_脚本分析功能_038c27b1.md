# AI 脚本分析功能实施计划

## 1. 主进程 AI 服务（src/main/aiService.js，新建）
- 纯函数导出（不依赖 electron，便于测试）：`resolveEndpoint(baseUrl)`（自动补全 /chat/completions、https/localhost 校验）、`buildMessages(content)`（ai.md 的 System/User Prompt）、`parseAnalysisJson(text)`（剥围栏→JSON.parse→截取大括号重试）、`sha256(content)`
- AIService 类（懒加载 electron / simple-db）：
  - `getSettings()` 返回 {baseUrl, model, temperature, sse, hasKey, keyPlainFallback}，不回传 Key
  - `saveSettings(payload)`：校验 URL；apiKey 留空则保留旧值；safeStorage 可用则 `encryptString`→base64 存 settings.ai（`apiKeyEnc`），否则明文 `apiKeyPlain` + fallback 标记
  - `chat(messages, {timeout})`：原生 fetch POST endpoint，Bearer Key，超时 AbortController 默认 120s，非 200 抛出带状态码/响应体摘要的错误
  - `testConnection()`：最小消息「回复 ok」验证
  - `analyze({scriptId, scriptName, content, force})`：>30000 字符拒绝；hash 缓存命中且非 force 直接返回；调模型→解析→写 `script_ai_analyses`（每脚本仅保留最新一条）
  - `getAnalysis(scriptId)`、`deleteAnalyses(scriptIds)`
  - `batchAnalyze(scriptIds, {force}, onProgress)`：并发 2 的 worker 池 + 取消标志 `batchCancelled`
- main.js 注册 IPC：`ai:getSettings / ai:saveSettings / ai:testConnection / ai:analyze / ai:getAnalysis / ai:deleteAnalyses / ai:batchAnalyze / ai:batchCancel`；批量进度经 `mainWindow.webContents.send('ai:batch-progress', {...})` 推送；`script:delete` 处理器内级联删除分析记录与快捷面板条目

## 3. 渲染层服务与 UI
### 3.1 src/renderer/js/services/aiService.js（新建）
- `window.AiService`：IPC 封装（getSettings/saveSettings/testConnection/analyze/getAnalysis/batchAnalyze/batchCancel/deleteAnalyses）+ `onBatchProgress(cb)` 订阅
### 3.2 src/renderer/js/aiAnalysisUI.js（新建）
- `window.AIAnalysisUI.renderCard(record)`：交通灯卡片（risk_level 徽标、摘要、严重风险列表、依赖、健壮性评分、推荐改动、时间+模型；parse_error/error 降级展示）

- `window.AIAnalysisUI.showBatchDialog(scripts, {onDone})`：批量弹窗——跳过已分析默认勾选、进度条、逐行状态、取消、汇总；>20 个二次确认
