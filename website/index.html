功能特性

从主机纳管到任务编排，覆盖运维自动化的完整链路

主机管理

增删改查、标签分类、Excel/CSV 批量导入导出、批量连接测试与 Ping 探测。

脚本管理

在线编辑器、目录树分类、参数模板化、快捷面板与语法高亮。

任务执行

批量并发执行、实时进度监控、并发数与超时自定义、支持 sudo。

工程任务

多步骤任务编排（脚本 + 文件上传混合）、定时执行、企业微信 Webhook 通知。

文件传输

批量 SFTP 上传、冲突策略（覆盖 / 备份 / 跳过）、断点进度反馈。

执行历史

详细执行日志、结果筛选分析、CSV / JSON 一键导出。

数据备份

自动定时备份、全量导入导出、自定义备份目录。

仪表盘

主机统计、今日执行次数、成功率、待办任务一览。

三步开启批量运维

零外部依赖，安装即用

01

导入主机

Excel / CSV 批量导入主机清单，或逐台录入；批量连接测试一键纳管。

02

编排脚本

在线编辑脚本并参数模板化，按目录分类管理，沉淀团队脚本资产。

03

批量执行

选择主机与脚本并发执行，实时监控进度，结果自动归档并可导出报告。
