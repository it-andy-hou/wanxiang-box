使用指南

从安装到批量运维，十分钟上手万象匣

下载与安装 快速上手 功能使用 配置说明 常见问题

下载与安装

所有安装包均发布在 GitHub Releases，免安装、解压即用，无需外部数据库。

Windows

  1. 下载 万象匣-x.x.x-win.zip
  2. 解压到任意目录
  3. 双击 万象匣.exe 运行

macOS（Intel / Apple Silicon）

  1. 按芯片下载 x64 或 arm64 的 .dmg
  2. 拖入「应用程序」文件夹
  3. 首次打开若被拦截，见下方常见问题

Linux

  1. 下载 .AppImage
  2. chmod +x *.AppImage
  3. 双击或命令行运行
macOS 首次打开提示「无法验证开发者」或「已损坏」时，在终端执行 xattr -cr /Applications/万象匣.app 后即可正常打开。

快速上手

三步完成一次批量运维操作。

第 1 步：导入主机

  • 进入「主机管理」→「添加主机」，支持单台录入或批量录入模式；
  • 也可以通过「导入 Excel」按模板批量导入（IP、端口、用户名、密码、机房、环境、负责人等）；
  • 导入后使用「批量连接测试」（Ping / SSH 两种方式）验证主机可达性，状态自动回写。

第 2 步：准备脚本

  • 进入「脚本管理」在线编写 Shell 脚本，支持目录分类与参数模板化；
  • 常用脚本可加入「快捷面板」，执行时一键选取。

第 3 步：批量执行

  • 进入「脚本执行」，选择脚本与目标主机（支持按系统、应用、机房、环境、负责人筛选）；
  • 点击执行后实时查看每台主机的进度与输出；
  • 执行结果自动归档到「任务记录」，可导出 CSV / JSON 报告。

功能使用

各核心模块的使用要点。

主机管理

主机增删改查、标签分类、批量修改、Excel/CSV 导入导出、批量 Ping / SSH 连接测试、批量采集主机信息（CPU / 内存 / 磁盘 / OS）。

脚本执行 / 命令执行

脚本执行面向已沉淀的脚本资产；命令执行面向临时性命令。两者均支持并发执行、实时输出、sudo 提权，并发数与超时时间可在全局设置中调整。

工程任务

将「脚本 + 命令 + 文件上传」编排为多步骤工程，支持步骤依赖与拖拽排序。采用严格失败即停策略：任一步骤失败，整个工程立即中止。支持定时执行与企业微信 Webhook 结果通知。

文件上传

批量 SFTP 上传文件到多台主机，支持冲突策略（覆盖 / 备份 / 跳过）与目标目录自动创建。

任务调度

为脚本任务或工程任务设定未来执行时间，到点自动触发，调度列表支持调整时间与立即执行。

任务记录

全部执行历史按任务归档，可查看每台主机的 stdout / stderr / 退出码，支持筛选分析与导出。

配置说明

点击软件右上角齿轮图标进入全局设置。

执行参数

  • 默认并发数：1 ~ 20，批量执行时同时连接的主机数量；
  • 默认超时：最低 10 秒，单台主机执行超时后自动判定失败。

SSH 密钥

  • 首次启动自动生成 4096 位默认密钥对，存放于数据目录 ssh_keys/；
  • 可在设置中查看公钥、重新生成密钥，并将公钥一键配置到目标主机实现免密登录。

数据备份

  • 手动「导出全量数据」生成 JSON 备份文件，用于换机迁移；
  • 每日定时备份可自定义时间与保留份数，备份目录可更改；
  • 导入备份前会强制自动备份当前数据，导入后应用自动重启。

数据存储位置

# Windows
%APPDATA%\万象匣\
# macOS
~/Library/Application Support/万象匣/
# 目录内容
data/database.json   # 主机、脚本、任务等全部业务数据
ssh_keys/            # 默认 SSH 密钥对
task_logs/           # 任务执行日志
backups/             # 自动备份

常见问题

使用中遇到问题先看这里。

macOS 提示「无法打开，因为无法验证开发者」或「已损坏」？

应用未做 Apple 开发者签名公证，会被 Gatekeeper 拦截，两种解决方式：

1. 系统设置 → 隐私与安全性 → 找到拦截记录 → 点击「仍要打开」；

2. 终端执行：xattr -cr /Applications/万象匣.app 清除隔离属性后重新打开。

从旧版「SSH工具箱」升级，数据会丢失吗？

不会。新版首次启动时会自动检测旧版数据目录并完成迁移（数据库、任务日志、SSH 密钥、配置全部保留），无需手动操作。

SSH 连接测试失败怎么排查？

按顺序检查：

1. 主机 IP 与端口（默认 22）是否正确，能否 Ping 通；

2. 用户名密码是否正确（注意密码中的特殊字符）；

3. 目标主机 sshd 服务是否运行、防火墙是否放行；

4. 若使用密钥登录，确认公钥已写入目标主机的 ~/.ssh/authorized_keys。

批量执行时如何提升速度？

在右上角齿轮 → 全局设置中调大「默认并发数」（最大 20）。注意并发过高会加重本机与目标主机负载，生产环境建议从 5 ~ 10 开始。

需要 root 权限的命令怎么执行？

执行时勾选「使用 sudo」，软件会使用主机登录密码自动完成 sudo 提权，无需在脚本中手写密码。

换电脑了，数据怎么迁移？

旧电脑：右上角齿轮 → 数据备份 →「导出全量数据」得到 JSON 备份文件；新电脑：同一入口「导入全量数据」选择该文件，导入后应用自动重启即完成迁移。

如何获取新版本？

软件启动时会自动检测 GitHub Releases 上的最新版本，发现新版会弹窗提醒，点击即可前往下载页。也可以随时访问官网更新记录查看版本变化。

如何配置企业微信通知？

在工程任务中填入企业微信群的 Webhook 地址，工程执行完成或失败时会自动推送结果摘要到群里。可先用「测试 Webhook」按钮验证连通性。
