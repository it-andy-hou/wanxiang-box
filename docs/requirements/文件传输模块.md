# 文件传输模块需求

## 1. 模块概述

文件传输模块是万象匣的重要功能组件，基于SFTP协议提供安全、高效的文件上传和下载服务。支持单文件和批量文件传输，与主机管理模块深度集成，为运维人员提供便捷的文件管理能力。

## 2. 核心功能

### 2.1 文件上传功能

#### 2.1.1 单文件上传
```javascript
// 单文件上传接口
class FileUploader {
  async uploadFile(localPath, remotePath, hostInfo, options = {}) {
    const progressCallback = options.onProgress || (() => {});
    const sftpConnection = await this.getSFTPConnection(hostInfo);
    
    try {
      // 创建远程目录（如果不存在）
      await this.ensureRemoteDirectory(sftpConnection, remotePath);
      
      // 上传文件并监控进度
      await sftpConnection.fastPut(localPath, remotePath, {
        step: (totalTransferred, chunk, total) => {
          const progress = (totalTransferred / total * 100).toFixed(2);
          progressCallback(progress, totalTransferred, total);
        }
      });
      
      return {
        success: true,
        localPath,
        remotePath,
        fileSize: await this.getFileSize(localPath),
        transferTime: Date.now() - startTime
      };
    } catch (error) {
      return {
        success: false,
        error: error.message,
        localPath,
        remotePath
      };
    }
  }
}
```

### 2.2 文件下载功能

#### 2.2.1 单文件下载
```javascript
// 单文件下载接口
class FileDownloader {
  async downloadFile(remotePath, localPath, hostInfo, options = {}) {
    const progressCallback = options.onProgress || (() => {});
    const sftpConnection = await this.getSFTPConnection(hostInfo);
    
    try {
      // 检查远程文件是否存在
      const remoteStats = await sftpConnection.stat(remotePath);
      
      // 创建本地目录（如果不存在）
      await this.ensureLocalDirectory(localPath);
      
      // 下载文件并监控进度
      await sftpConnection.fastGet(remotePath, localPath, {
        step: (totalTransferred, chunk, total) => {
          const progress = (totalTransferred / total * 100).toFixed(2);
          progressCallback(progress, totalTransferred, total);
        }
      });
      
      return {
        success: true,
        remotePath,
        localPath,
        fileSize: remoteStats.size,
        transferTime: Date.now() - startTime
      };
    } catch (error) {
      return {
        success: false,
        error: error.message,
        remotePath,
        localPath
      };
    }
  }
}
```

### 2.4 传输管理

#### 2.4.1 传输队列管理
```javascript
class TransferQueue {
  constructor() {
    this.queue = [];
    this.activeTransfers = new Map();
    this.maxConcurrent = 5;
    this.retryAttempts = 3;
  }
  
  // 添加传输任务
  addTransfer(transferTask) {
    const task = {
      id: this.generateTaskId(),
      type: transferTask.type, // 'upload' | 'download'
      localPath: transferTask.localPath,
      remotePath: transferTask.remotePath,
      hostInfo: transferTask.hostInfo,
      priority: transferTask.priority || 'normal',
      status: 'pending',
      progress: 0,
      speed: 0,
      timeRemaining: 0,
      retryCount: 0,
      createTime: Date.now()
    };
    
    this.queue.push(task);
    this.processQueue();
    return task.id;
  }
  
  // 处理队列
  async processQueue() {
    const pendingTasks = this.queue.filter(t => t.status === 'pending');
    const runningCount = this.activeTransfers.size;
    
    if (runningCount < this.maxConcurrent && pendingTasks.length > 0) {
      const nextTask = this.selectNextTask(pendingTasks);
      await this.executeTransfer(nextTask);
    }
  }
}
```

## 3. 高级功能

### 3.1 文件同步功能
```javascript
class FileSyncManager {
  async syncDirectories(localDir, remoteDir, hostInfo, options = {}) {
    const syncStrategy = options.strategy || 'bidirectional'; // 'upload' | 'download' | 'bidirectional'
    const conflictResolution = options.conflictResolution || 'newer'; // 'newer' | 'local' | 'remote' | 'ask'
    
    // 1. 扫描本地和远程目录
    const localFiles = await this.scanLocalDirectory(localDir);
    const remoteFiles = await this.scanRemoteDirectory(remoteDir, hostInfo);
    
    // 2. 比较文件差异
    const differences = this.compareDirectories(localFiles, remoteFiles);
    
    // 3. 生成同步计划
    const syncPlan = this.generateSyncPlan(differences, syncStrategy, conflictResolution);
    
    // 4. 执行同步
    return await this.executeSyncPlan(syncPlan, localDir, remoteDir, hostInfo);
  }
}
```

### 5.2 核心实现架构
```javascript
// 文件传输核心类
class FileTransferManager {
  constructor() {
    this.transferQueue = new TransferQueue();
    this.sftpPool = new SFTPConnectionPool();
    this.progressEmitter = new EventEmitter();
  }
  
  // 统一传输接口
  async transfer(transferRequest) {
    const { type, files, source, target, options } = transferRequest;
    
    switch (type) {
      case 'upload':
        return await this.uploadFiles(files, target, options);
      case 'download':
        return await this.downloadFiles(files, target, options);
      case 'sync':
        return await this.syncDirectories(source, target, options);
    }
  }
}
```

-- 传输历史表
CREATE TABLE transfer_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    type TEXT NOT NULL,                    -- 'upload' | 'download' | 'sync'
    host_id INTEGER,                       -- 关联主机ID
    local_path TEXT NOT NULL,              -- 本地路径
    remote_path TEXT NOT NULL,             -- 远程路径
    file_count INTEGER DEFAULT 0,          -- 文件数量
    total_size INTEGER DEFAULT 0,          -- 总大小（字节）
    transferred_size INTEGER DEFAULT 0,    -- 已传输大小
    status TEXT DEFAULT 'pending',         -- 'pending' | 'running' | 'completed' | 'failed' | 'cancelled'
    start_time DATETIME,                   -- 开始时间
    end_time DATETIME,                     -- 结束时间
    error_message TEXT,                    -- 错误信息
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(host_id) REFERENCES hosts(id)
);

-- 创建索引
CREATE INDEX idx_transfer_history_host_id ON transfer_history(host_id);
