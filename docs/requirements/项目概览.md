# 项目概览

## 1. 项目背景

### 1.1 项目背景
当前的 Toolboxs 是基于 Web CGI 架构的系统管理工具集，运行在 Linux 环境下，通过浏览器提供服务。为了提高易用性和部署便利性，计划将其重构为 Windows 平台下的桌面小工具。

### 1.2 项目目标
- 将现有 Web 界面工具转换为 Windows 桌面应用
- 保持现有功能完整性
- 提升用户体验和操作便利性
- 降低部署和维护成本

## 2. 现状分析

### 2.1 当前架构
```
Web 浏览器 → Apache/Nginx → CGI 脚本 → Linux 系统命令 → 远程服务器
```

### 2.2 功能模块重新设计

原有功能都是基于脚本实现的批量运维工具，现在将其抽象为三个核心模块：

#### 2.2.1 主机管理模块
- **主机生命周期管理**
  - 新主机添加（IP、系统、应用、机房、环境、认证信息）
  - 自动SSH免密配置
  - 自动收集主机基础信息（CPU、内存、系统版本等）
  - 主机状态监控和健康检查

- **智能筛选和搜索**
  - 按属性筛选（系统、应用、机房、环境、状态）
  - 关键字模糊搜索
  - 多条件组合筛选
  - 收藏夹和快速访问

- **便捷操作**
  - 选中主机直接SSH登录
  - 批量选择和操作
  - 主机分组管理

#### 2.2.2 脚本管理模块
- **脚本资源统一管理**
  - 目录分类管理（系统检查、网络测试、运维工具等）
  - 脚本在线编辑和版本管理
  - 脚本备注说明和使用文档
  - 脚本参数模板化

- **脚本类型**
  - SSH免密检查脚本
  - 系统内核参数检查脚本
  - 网络连通性测试脚本
  - 系统信息收集脚本
  - DNS/NTP检查脚本
  - 密码策略检查脚本
  - 定时任务管理脚本
  - 自定义运维脚本

#### 2.2.3 任务执行模块
- **批量执行引擎**
  - 选择目标主机（支持多选、分组选择）
  - 选择执行脚本
  - 配置执行参数
  - 并发执行控制
  - 实时进度监控

- **执行结果管理**
  - 结果实时展示
  - 成功/失败统计
  - 结果导出（CSV、Excel）
  - 执行历史记录
  - 异常告警通知

#### 2.2.4 文件传输模块
- **文件上传下载**
  - 单文件和批量文件传输
  - 目录递归上传下载
  - 断点续传和压缩传输
  - 传输进度监控和队列管理
  - 文件完整性校验

- **远程文件管理**
  - 远程文件浏览器
  - 文件和目录操作（创建、删除、重命名）
  - 文件预览和在线编辑
  - 文件搜索和筛选
  - 文件同步功能

- **传输优化**
  - 多线程并发传输
  - 带宽控制和网络优化
  - 自动重试和错误恢复
  - 传输历史和审计日志

#### 2.2.5 通知告警模块
- **企业微信集成**
  - 主机状态变更通知
  - 任务执行结果推送
  - 系统异常告警通知
  - 自定义告警规则和阈值
  - 支持@指定人员或群组

- **通知场景**
  - 主机新增/删除/状态变更
  - 脚本执行成功/失败
  - 文件传输完成/异常
  - 系统资源告警（CPU、内存、磁盘）
  - 安全事件告警

#### 2.2.6 数据管理模块
- **数据备份恢复**
  - 主机配置自动备份
  - 脚本库版本管理和备份
  - 用户设置和偏好备份
  - 数据导出导入（JSON/Excel格式）
  - 灾难恢复快速还原

- **日志管理与审计**
  - 用户操作日志详细记录
  - 脚本执行完整日志链路
  - 系统运行日志监控
  - 日志搜索、过滤、统计分析
  - 日志自动轮转和归档
  - 合规审计报告生成

## 3. 技术选型

### 3.1 确定方案：Electron + Node.js ✅
**优势：**
- 可以复用现有的HTML/CSS/JavaScript前端代码
- 跨平台支持
- 丰富的生态系统
- 易于维护和更新
- SSH处理库成熟稳定
- 异步处理天然适配批量操作

**技术栈：**
- 前端：Electron + HTML5 + CSS3 + JavaScript
- 后端逻辑：Node.js
- SSH连接：node-ssh 库
- 系统命令：child_process 模块
- 数据存储：SQLite（主机信息、审计日志）
- 数据处理：xlsx、csv-parser（Excel/CSV导入导出）

## 4. 核心价值

### 4.1 用户体验提升
- **一站式主机管理**：从添加到配置到监控的完整生命周期
- **直观操作界面**：桌面应用，无需浏览器依赖
- **智能筛选搜索**：快速定位目标主机
- **自动化程度高**：减少手动配置工作

### 4.2 运维效率提升
- **批量操作能力**：支持大规模主机批量管理
- **脚本统一管理**：避免脚本分散和版本混乱
- **执行结果可追溯**：完整的操作历史和审计日志
- **任务并发执行**：大幅提升执行效率

### 4.3 部署维护简化
- **单体应用部署**：无需复杂的Web服务器配置
- **本地数据存储**：减少外部依赖
- **跨平台兼容**：Windows/macOS/Linux通用
- **自动更新机制**：便于版本管理和功能迭代
