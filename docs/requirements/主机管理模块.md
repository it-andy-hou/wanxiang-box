# 主机管理模块需求

## 1. 模块概述

主机管理是万象匣的核心基础功能，为其他所有功能模块提供主机数据来源。基于现有的`servers.csv`文件结构设计，提供完整的主机信息管理能力。

## 2. 数据模型

### 2.1 基于servers.csv的字段结构
```
系统名称,应用名称,IP,用户,cpu,内存,机房
```

### 2.2 扩展后的完整数据模型
- **系统名称**：服务器所属的系统（如：统一接入网关IAR-接入）
- **应用名称**：运行的应用服务（如：iar_trade-macs）
- **IP地址**：服务器IP地址（唯一标识）
- **用户名**：SSH登录用户（通常为root）
- **CPU信息**：处理器配置信息
- **内存信息**：内存配置信息
- **机房位置**：服务器所在机房（如：荷丹路、西信、金桥、东城根、锦绣申江等）
- **认证方式**：SSH密钥或密码认证
- **连接状态**：在线/离线/未知
- **标签**：自定义标签分类

## 5. 技术实现

### 5.1 数据库设计
```sql
-- 主机信息表
CREATE TABLE hosts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    system_name TEXT NOT NULL,           -- 系统名称
    app_name TEXT NOT NULL,              -- 应用名称
    ip TEXT NOT NULL UNIQUE,             -- IP地址
    username TEXT NOT NULL DEFAULT 'root', -- 用户名
    cpu TEXT,                            -- CPU信息
    memory TEXT,                         -- 内存信息
    datacenter TEXT,                     -- 机房
    auth_type TEXT DEFAULT 'key',       -- 认证类型
    key_path TEXT,                       -- SSH密钥路径
    password TEXT,                       -- 密码（加密存储）
    port INTEGER DEFAULT 22,            -- SSH端口
    status TEXT DEFAULT 'unknown',      -- 连接状态
    tags TEXT,                          -- 标签（JSON格式）
    description TEXT,                   -- 描述信息
    last_check_time DATETIME,           -- 最后检查时间
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(ip, port)
);

-- 创建索引提升查询性能
CREATE INDEX idx_hosts_system_name ON hosts(system_name);
CREATE INDEX idx_hosts_app_name ON hosts(app_name);
CREATE INDEX idx_hosts_datacenter ON hosts(datacenter);
CREATE INDEX idx_hosts_status ON hosts(status);
```

### 5.2 数据迁移方案
提供现有`servers.csv`数据的无缝迁移：

1. **自动检测**：启动时检测workspace下的servers.csv文件
2. **一键导入**：提供导入向导，预览导入数据
3. **数据映射**：自动映射CSV字段到数据库字段
4. **备份原文件**：导入前自动备份原CSV文件
5. **增量更新**：支持后续CSV文件的增量导入

```javascript
// CSV导入实现
async function importServersCSV(filePath) {
  const hosts = [];
  return new Promise((resolve, reject) => {
    fs.createReadStream(filePath)
      .pipe(csv({
        headers: ['system_name', 'app_name', 'ip', 'username', 'cpu', 'memory', 'datacenter']
      }))
      .on('data', (data) => {
        hosts.push({
          systemName: data.system_name,
          appName: data.app_name,
          ip: data.ip,
          username: data.username || 'root',
          cpu: data.cpu,
          memory: data.memory,
          datacenter: data.datacenter
        });
      })
      .on('end', () => resolve(hosts))
      .on('error', reject);
  });
}
```
