# 任务执行模块需求

## 1. 模块概述

任务执行模块是万象匣的核心执行引擎，负责批量自动化运维任务的执行、监控和结果管理。

## 2. 核心功能

### 2.1 批量执行流程
```
任务创建 → 目标选择 → 脚本选择 → 参数配置 → 批量执行 → 结果收集
```

### 2.2 目标主机选择
- **多选模式**：支持Ctrl/Shift多选主机
- **分组选择**：按系统、机房、环境批量选择
- **筛选选择**：基于筛选条件自动选择
- **文件导入**：导入IP列表文件
- **历史记录**：复用历史选择记录

### 2.3 执行控制
- **并发控制**：可配置最大并发连接数(默认20)
- **超时设置**：单个任务超时时间(默认300秒)
- **错误策略**：遇错继续/遇错停止
- **重试机制**：失败自动重试(最多3次)
- **执行顺序**：串行/并行执行模式

### 2.4 实时监控
```javascript
// 执行监控器
class TaskMonitor {
  constructor() {
    this.tasks = new Map();
    this.listeners = [];
  }
  
  // 监控任务执行
  monitorTask(taskId) {
    const task = this.tasks.get(taskId);
    
    // 实时状态更新
    this.updateTaskStatus(task);
    
    // 进度计算
    const progress = this.calculateProgress(task);
    
    // 性能监控
    const performance = this.monitorPerformance(task);
    
    // 通知监听器
    this.notifyListeners(taskId, {
      status: task.status,
      progress,
      performance
    });
  }
}
```

## 4. 结果管理

### 4.1 结果收集和展示
- **实时结果**：任务执行过程中实时显示结果
- **状态标识**：成功(绿)、失败(红)、运行中(黄)、等待(灰)
- **详细信息**：点击查看每台主机的详细执行结果
- **错误诊断**：失败任务的错误原因分析

### 4.2 结果导出
```javascript
// 结果导出器
class ResultExporter {
  // 导出格式
  exportFormats = ['CSV', 'Excel', 'JSON', 'HTML'];
  
  // 导出CSV
  async exportToCSV(taskResults) {
    const headers = ['主机IP', '状态', '执行时间', '结果', '错误信息'];
    const rows = taskResults.map(result => [
      result.host,
      result.status,
      result.duration,
      result.output,
      result.error || ''
    ]);
    
    return this.generateCSV(headers, rows);
  }
  
  // 导出执行报告
  async exportReport(taskInfo, results) {
    const report = {
      taskInfo: {
        name: taskInfo.name,
        script: taskInfo.script,
        executedAt: taskInfo.executedAt,
        totalHosts: results.length
      },
      summary: this.generateSummary(results),
      details: results,
      statistics: this.generateStatistics(results)
    };
    
    return this.generateReport(report);
  }
}
```

## 5. 技术实现

### 5.1 并发执行引擎
```javascript
class ConcurrentExecutor {
  constructor(maxConcurrency = 20) {
    this.maxConcurrency = maxConcurrency;
    this.running = new Set();
    this.queue = [];
  }
  
  async execute(tasks) {
    for (const task of tasks) {
      if (this.running.size < this.maxConcurrency) {
        this.runTask(task);
      } else {
        this.queue.push(task);
      }
    }
  }
  
  async runTask(task) {
    this.running.add(task);
    
    try {
      const result = await this.executeTask(task);
      this.handleSuccess(task, result);
    } catch (error) {
      this.handleError(task, error);
    } finally {
      this.running.delete(task);
      this.processQueue();
    }
  }
}
```

### 5.2 数据库设计
```sql
-- 任务表
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    script_id INTEGER NOT NULL,
    parameters TEXT,              -- JSON格式参数
    target_hosts TEXT,            -- JSON格式主机列表
    status TEXT DEFAULT 'pending', -- pending/running/completed/failed
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    started_at DATETIME,
    completed_at DATETIME,
    FOREIGN KEY(script_id) REFERENCES scripts(id)
);

-- 任务执行结果表
CREATE TABLE task_results (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id INTEGER NOT NULL,
    host_ip TEXT NOT NULL,
    status TEXT NOT NULL,         -- success/failed/timeout
    output TEXT,                  -- 执行输出
    error_message TEXT,           -- 错误信息
    started_at DATETIME,
    completed_at DATETIME,
    duration INTEGER,             -- 执行时长(秒)
    FOREIGN KEY(task_id) REFERENCES tasks(id)
);
```
