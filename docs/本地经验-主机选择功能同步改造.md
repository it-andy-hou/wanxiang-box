## 二、同步改造需要改动的地方（Checklist）

### 1. index.html 对应页面区块

已选主机区域统一为以下结构（以文件上传页为例，ID 按上表替换）：

- 按钮行：`class="te-host-btns"`，内含「选择」「清空」两个 `btn btn-secondary btn-sm` + `<span class="te-host-count">` 计数
- 编辑提示：`<div class="te-host-edit-hint" id="teFileUploadHostEditHint" style="display:none;">`，带眼睛图标 SVG，文案为「如需增加或移除主机，点击「编辑已选主机」，确认后整体替换」
- 列表容器：`<div id="selectedFileUploadHostsList" class="te-host-chips">`，空态用 `<span class="te-host-empty">未选择主机</span>`
- 文件上传页因 bento 卡片布局，列表容器额外保留 `style="flex: 1;"`

### 2. 页面 JS 的三处逻辑

**（1）`bindEvents()` 中新增事件委托监听**（注意 fileUpload.js 有 `eventsBound` 幂等守卫，只需加在守卫内一次）：

```js
const selectedHostsList = document.getElementById('selectedFileUploadHostsList');
if (selectedHostsList) {
    selectedHostsList.addEventListener('click', handleSelectedHostsListClick);
}
```

**（2）`updateSelectedHostsList()` 重写**，包含四个要点：

- 按钮双态：已选主机 > 0 时文字变「编辑已选主机」，否则「从主机管理选择」，同时更新 `title`
- 编辑提示 `editHint.style.display` 随选择状态显隐
- 空态：`<span class="te-host-empty">未选择主机</span>`
- 非空态：渲染 `<table class="table te-host-table">`，列为 IP / 应用名称 / 负责人 / 删除按钮；
  **按 `selectedHosts` 数组顺序渲染**（`selectedHosts.map(id => selectedHostsData.find(...))`），
  删除按钮用 `class="te-host-remove-btn"` + `data-host-id`

**（3）新增 `handleSelectedHostsListClick(e)`**：通过 `e.target.closest('.te-host-remove-btn')` 事件委托，从 `selectedHosts` 中过滤掉该 id 后调 `updateSelectedHostsList()`。

### 3. 主机选择弹窗（createHostSelectorDialog）

三个页面各自的弹窗实现保持一致：

- 表格滚动区 `max-height: 520px`
- 五级筛选级联联动（系统/应用/机房/环境/负责人）
- 搜索框 + IP 批量识别选中
- 「确定」按钮整体替换 `selectedHosts` 并调 `updateSelectedHostsList()`

### 4. CSS：不要新增样式

复用 [components.css](../src/renderer/css/components.css) 中已有类（约 3257-3343 行）：
`te-host-btns`、`te-host-count`、`te-host-chips`、`te-host-empty`、`te-host-table`、`te-host-remove-btn`、`te-host-edit-hint`。

## 三、容易踩的坑

1. **字段兼容**：主机数据同时存在驼峰和下划线字段，取值要写成 `host.appName || host.app_name`、`host.systemName || host.system_name`。
2. **转义**：所有插入 HTML 的主机字段必须过 `escapeHtml()`。
3. **事件委托而非逐行绑定**：删除按钮在每次渲染后重建，直接绑会漏绑或重复绑，必须委托到列表容器。
4. **不要手动改样式类名**：`te-host-*` 是全局共享类，改名会影响另外两个页面。
5. **fileUpload.js 的 init 幂等**：该文件模块自执行 + `window.FileUploadPage.init` 可能各调一次，任何新事件绑定必须放进 `eventsBound` 守卫内。
