# 滚动和分页问题修复

## 问题描述

用户报告了两个主要问题：

1. **控制台报错**: `navigation.js:63 页面不存在: 1`
2. **双滚动条问题**: 界面出现了重复的滚动条，影响用户体验

## 问题分析

### 问题1: navigation.js错误

**根本原因**: 在 `SSHToolsApp` 类中存在属性名冲突：
- `this.currentPage = 'hosts'` - 用于导航管理器的页面ID  
- `this.currentPage = 1` - 用于分页功能的页码

当调用 `navigationManager.navigateTo(this.currentPage)` 时，传递的是数字`1`而不是字符串`'hosts'`，导致导航管理器无法找到对应的页面配置。

### 问题2: 双滚动条问题

**根本原因**: CSS布局中存在嵌套的滚动容器：
- `.page-content` 设置了 `overflow: hidden` 和 `flex-direction: column`
- `.view-container` 设置了 `overflow-y: auto` 和 `max-height`
- `.table-container` 也设置了 `overflow-y: auto` 和 `max-height`

这造成了多层嵌套的滚动容器，导致出现多个滚动条。

## 解决方案

### 修复1: 属性名冲突

将分页相关的 `currentPage` 重命名为 `paginationCurrentPage` 以避免冲突：

```javascript
// 修改前
this.currentPage = 'hosts';    // 导航用
this.currentPage = 1;          // 分页用 - 冲突！

// 修改后  
this.currentPage = 'hosts';           // 导航用
this.paginationCurrentPage = 1;       // 分页用
```

**涉及文件**: `src/renderer/js/app.js`

**修改内容**:
- 构造函数中的属性声明
- 所有分页相关方法中的属性引用
- 事件处理器中的属性引用

### 修复2: 双滚动条问题

重新设计CSS布局结构，使用单一的滚动容器：

```css
/* 修改前 - 多层滚动 */
.page-content {
    overflow: hidden;
    display: flex;
    flex-direction: column;
}
.view-container {
    overflow-y: auto;
    max-height: calc(100vh - 320px);
}
.table-container {
    overflow-y: auto;
    max-height: calc(100vh - 320px);
}

/* 修改后 - 单层滚动 */
.page-content {
    overflow: hidden;
    display: flex;
    flex-direction: column;
}
.view-container {
    flex: 1;
    overflow: hidden;
}
.table-container {
    height: 100%;
    overflow-y: auto;
}
```

**涉及文件**: `src/renderer/css/main.css`

**核心改动**:
- 移除 `.view-container` 的 `max-height` 和 `overflow-y`
- 将 `.table-container` 改为 `height: 100%`
- 移除响应式样式中的重复 `max-height` 设置

## 修复详情

### JavaScript修改 (app.js)

```javascript
// 构造函数属性重命名
this.paginationCurrentPage = 1;  // 原: this.currentPage = 1

// 事件绑定更新
Utils.on('#prevPageBtn', 'click', () => this.goToPage(this.paginationCurrentPage - 1));
Utils.on('#nextPageBtn', 'click', () => this.goToPage(this.paginationCurrentPage + 1));

// 方法内属性引用更新
goToPage(pageNumber) {
    this.paginationCurrentPage = pageNumber;  // 原: this.currentPage = pageNumber
    // ... 其他更新
}
```

### CSS修改 (main.css)

```css
/* 视图容器 - 移除滚动，只做布局 */
.view-container {
    flex: 1;
    overflow: hidden;  /* 原: overflow-y: auto */
}

/* 表格容器 - 负责实际滚动 */
.table-container {
    height: 100%;      /* 原: max-height: calc(100vh - 320px) */
    overflow-y: auto;
}

/* 卡片和分组视图 */
#cardView .hosts-grid,
#groupView .host-groups {
    height: 100%;      /* 原: max-height: 100% */
    overflow-y: auto;
}
```
